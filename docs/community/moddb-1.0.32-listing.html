Distant Vistas — Official 1.0.32

Client-side level-of-detail mod for Vintage Story. Fork of Vintage Horizons (AliasFactory, MIT). Draws real 3D far terrain from a persistent per-world cache built from chunk data the client already received. Compatible with Vintage Story 1.22.5–1.22.7.

Project scale

  • ~31,000 lines of C# mod source
  • ~8,800 lines of automated check / test code
  • ~40,000 lines C# total (mod + tests)
  • 123 C# source files · 225 git commits
  • 57 render modules · 11 LOD core · 14 networking · storage and config layers
  • 10 GLSL shader files (~1,280 lines): far-terrain draw, Farseer region overlay, vanilla chunk edge overrides
  • 16 build / bench / test scripts

What is in the codebase

  • LOD pipeline — block capture, RLE sections, 3D meshing, mip pyramid, worker thread, SQLite persistence
  • Render — terrain draw, login overlay and scout bake, live seasonal colour sampling, night ambient, frustum and occlusion, gap-fill and parent coverage rules
  • Farseer integration — region shader overlays (no Harmony patches), visit-mask silhouettes, heightmap enrichment, onset at 4.5× view distance + 700 blocks
  • Networking (optional) — server assist, scout protocol, shared cache assist for multiplayer
  • Shaders — lodterrain (far mesh + season clock), farseer-region / region (silhouette band), patched chunkopaque / chunktransparent / chunkliquid / chunktopsoil (full alpha at view-distance ring)

Capabilities (1.0.32)

  • Unlimited render-distance cap (.dvfar 0)
  • Real 3D far terrain at block resolution near the player; coarser mips farther out
  • Translucent water over sealed seabed skin (no cave cutaway through ocean)
  • Live seasonal colour on vegetation; rock, snow, and water excluded from fake autumn wash
  • December frost on tree crowns; winter ground mottled brown/tan/olive, not a white sheet
  • Join overlay (singleplayer and Distant Vistas servers): four-season splash, scouts bake far land while the player stays at spawn; 16 parallel scouts; graphics view held at 750 then restored
  • Vanilla public servers: overlay skipped — no teleports or gamemode commands; capture while you walk
  • Visited captured land stays drawn behind and beside the camera
  • Night: same live ambient multiply as vanilla chunk shaders
  • Farseer can run in the background; Distant Vistas tiles on top where captured; gray tent + black tips at far rim
  • ChunkLOD / TopoHorizon: mod defers unless .dvdefer off

People ask: what is the difference from Vintage Horizons?

Same starting point — persistent LOD cache from client chunk data. The draw path and polish diverge:

TopicVintage HorizonsDistant Vistas
Missing detailCoarse parent plate as stand-in → giant square shelves with sheer wallsNo parent box stand-in; incomplete L0 stays off screen until real land exists
Camera trailWanted-level window drops captured tiles behind you → sky holes when flying awayCaptured L0/L1 stays in the draw set behind and beside the camera
Vanilla handoffHorizontal disc — looking down from altitude hides LOD incorrectly3D vanilla-owns plus pitch; look-down still draws LOD where vanilla has no chunks
NightStored albedo lit with calendar sun colour → orange far band after vanilla goes darkStored albedo × live ambient (same clock as chunk shaders)
SeasonClimate in slow table; far vegetation snaps grey-green when leaving vanilla rangeClimate in slow table + live seasonRel shader clock on vegetation slots only
View-distance edgeStock vanilla chunk shaders fade alpha → white fog slice / mid-mountain cutPatched chunk vertex shaders force full alpha so LOD joins at full strength
FarseerMod could sit idle when Farseer installedDraws with Farseer behind; shader overlay without Harmony; visit-mask silhouettes
LoginHop-scan teleported the player cell to cell1.0.24+: player stays at spawn; scout stream centers bake visit cells (1.0.30+ player-style viewers; 1.0.31+ 16 parallel scouts)
OceanCave interiors visible through transparent water (“cake slice”)Sealed seabed skin under water; opaque mesh only to first air gap below water bottom
CaptureOne quadrant could mark whole L0 section captured → checkerboard holesSkip only when this chunk’s quadrant is already captured (0.7.7+)

Install

Drop distantvistas_1.0.32.zip in the Mods folder. Do not extract. Fully quit Vintage Story, then start again. Leaving to the menu does not reload a replaced zip.

Recommended companion mod: Client MeshRef Leak Fix (vsvaogc) — client only.

In-game commands

  • .dvistas — status, mesh counts, far edge, defer state
  • .dvdetail [blocks] — detail halving distance (default 512)
  • .dvfar <blocks> — cap LOD render distance (0 = unlimited)
  • .dvdefer [on|off] — defer when ChunkLOD or TopoHorizon draws (restart to apply)
